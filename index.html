Overview

把日常里值得留存的，
好好收起来。

从订阅支出到每日记录，从阅读收藏到资产轨迹——所有数字生活的碎片，都有一个安放的位置。

01
订阅管理
记录小报童、知识星球、软件订阅等，统计月费年费，追踪到期时间。
02
日记
记录每一天，统计写日记的覆盖率，看看你坚持了多少天。
03
公众号阅读
收藏感兴趣的公众号文章，标记已读，按号分组，随时回顾。
04
资产记录
汇总所有资产分类，记录每次快照，用折线图追踪净资产变化轨迹。
05
GitHub 创作者
收录优质 GitHub 创作者的 AI Prompt 与工具合集，持续更新。
